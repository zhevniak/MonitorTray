# MonitorTray

**Включение и выключение отдельных мониторов прямо из системного трея Windows — без DDC/CI.**

[English readme is here](README.md)

Второй (третий…) монитор нужен не всегда, но он продолжает светить в углу? MonitorTray добавляет в трей маленький значок (как [Twinkle Tray](https://github.com/xanderfrangos/twinkle-tray) для яркости), где каждый монитор переключается одним кликом: клик — выключил, ещё клик — включил.

Работает даже с мониторами, **не поддерживающими управление питанием по DDC/CI** — программы вроде use.ScreenOff на них пишут «Power control unavailable», а MonitorTray использует тот же механизм, что и встроенные «Параметры экрана → Отключить этот экран» (Windows Display Config API / CCD). Монитор реально теряет сигнал и засыпает — как будто выдернули кабель.

## Возможности

- 🖥 **Питание каждого монитора из трея** — левый или правый клик по значку, дальше клик по монитору
- 🔌 **DDC/CI не нужен** — работает там, где DDC-утилиты сдаются
- 📏 **Помнит разрешение и частоту** — при включении монитора возвращается его прежний режим (например, кастомный 1600×1024@165), а не нативный по умолчанию
- 🌙 **«Погасить все экраны»** — DPMS-сон всех мониторов до первого движения мыши
- 🚀 **Автозапуск** — включается галочкой прямо в меню трея
- 🪶 **Крошечная (~90 КБ), без зависимостей и прав администратора** — обычное приложение .NET Framework 4.x (встроен в Windows 10/11)
- 📦 **Установщик одним файлом + корректное удаление** — установка в профиль пользователя, запись в «Приложения и возможности»

## Установка

На странице [Releases](../../releases) два варианта:

1. **`MonitorTray.exe`** (или `MonitorTray-1.0-portable.zip`) — рекомендуется. Полностью портативный: просто запусти, ничего не устанавливается. Автозапуск включается галочкой в меню трея («Запускать при входе в Windows»).
2. **`MonitorTraySetup.exe`** — необязательный установщик: ставит в профиль пользователя (`%LOCALAPPDATA%`), создаёт ярлыки и запись в «Приложениях и возможностях» для удаления.

Права администратора не нужны.

## Как пользоваться

Левый (или правый) клик по значку в трее:

```
Мониторы — вкл: 2
──────────────────────────
●  DELL S2721DGF  — основной      ← клик, чтобы выключить
●  Redmi 27 NQ                    ← клик, чтобы выключить
──────────────────────────
Погасить все экраны (до 1-го движения мыши)
──────────────────────────
Запускать при входе в Windows
О программе
Выход
```

- `●` — монитор включён; `○` — выключен (оранжевый, клик — включить обратно)
- Выключение основного монитора поддерживается: оставшийся становится основным, при включении всё возвращается
- Выключить **последний** активный монитор нельзя — это защита от чёрного экрана

## Командная строка

`MonitorTray.exe` умеет и из консоли (для скриптов и глобальных хоткеев):

```
MonitorTray list          список мониторов (номер, имя, состояние, разрешение)
MonitorTray off 2         выключить монитор №2
MonitorTray on 2          включить монитор №2
MonitorTray toggle 2      переключить
MonitorTray restore       вернуть сохранённую Windows топологию (аварийно)
MonitorTray dpms-off      сон всех экранов
MonitorTray dbg           диагностика дисплеев (только чтение)
```

Нумерация после выключения сдвигается — выключенные идут в конце списка, перед следующей командой гляньте `list`.

## Как это устроено (технические подробности)

MonitorTray работает через Windows **CCD API** (Connect and Configure Display):

- `QueryDisplayConfig` / `SetDisplayConfig` — чтение и изменение активной топологии дисплеев
- выключение = отправка топологии без пути этого монитора: Windows гасит видеовыход, монитор теряет сигнал и засыпает (то же, что «Отключить этот экран» в Параметрах)
- включение = возврат сохранённого пути из `QDC_ALL_PATHS` + запасной вариант через `ChangeDisplaySettingsEx`
- имена мониторов берутся из WMI (`WmiMonitorID`) и EDID-записей реестра, сопоставление с CCD-таргетами — по UID и позиции исходного режима

Уже учтены реальные особенности (найдены на Windows 10 22H2 + NVIDIA):

- `QueryDisplayConfig` / `DisplayConfigGetDeviceInfo` возвращают `ERROR_INVALID_PARAMETER` при непустом указателе `topologyId` и при драйверах с «виртуальными режимами» (WDDM 2.7+) без флага `SDC_VIRTUAL_MODE_AWARE` — обе ситуации обнаруживаются и обходятся
- некоторые системы отвергают переиндексированные массивы режимов — массив режимов всегда передаётся в исходном виде
- для выключения основного монитора оставшемуся монитору позиция исправляется на (0,0)

Всё проверено на живом железе (Dell S2721DGF + Redmi 27 NQ, RTX 4060 Ti), включая полные циклы выключения/включения основного и второго монитора с кастомными разрешениями.

## Сборка из исходников

Ни Visual Studio, ни SDK не нужно — скрипт сборки использует компилятор C#, входящий в состав Windows:

```
build.cmd
```

На выходе: `MonitorTray.exe` (программа) и `MonitorTraySetup.exe` (установщик одним файлом, с программой и деинсталлятором внутри).

Весь код — в одном небольшом файле `MonitorTray.cs` (~1200 строк, совместим с C# 5), иконка генерируется `icongen.cs`, установщик/деинсталлятор — `Setup.cs` / `Uninstall.cs`.

## Ложные срабатывания антивирусов

MonitorTray — маленький **неподписанный** .NET-exe, который меняет топологию дисплеев, умеет добавлять автозапуск в реестр, а установщик распаковывает вложенные exe — такое сочетание машинно-обучаемые движки некоторых антивирусов помечают генериками (`Wacatac.B!ml`, `MSILHeracles` и т.п.). Это **ложное срабатывание**: проект полностью открыт, весь код — в этом репозитории, а файлы в Releases собираются из этого же кода автоматически на GitHub Actions.

Что с этим делается:
- основной вариант загрузки — **портативный `MonitorTray.exe` / zip**: он вызывает намного меньше эвристик, чем любой установщик
- заявки о ложных срабатываниях отправляются вендорам (Microsoft, BitDefender, McAfee и их клоны) — детекты обычно снимают за дни/недели
- в планах — сертификат подписи кода для open-source разработчиков, это устраняет причину

Если антивирус ругается: проверь файл на [VirusTotal](https://www.virustotal.com) и сверь хэши с указанными в релизе, собери exe сам из исходников (`build.cmd`, на любой Windows без установки чего-либо) или добавь исключение.

## Если что-то пошло не так

- **Монитор не включился** — `MonitorTray restore`, или Параметры → Дисплей, или передёрнуть кабель
- **После включения изменилось разрешение** — вернётся автоматически на следующем цикле выключение/включение (текущий режим запоминается в момент выключения); файл соответствий: `%APPDATA%\MonitorTray_modes.txt`
- **Значок пропал** — посмотрите в области «^» рядом с треем
